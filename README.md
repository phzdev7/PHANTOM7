# 🚀 PHANTOM 7

> Projeto de jogo 2D desenvolvido em **Java** como forma de praticar programação orientada a objetos, eventos de teclado e desenvolvimento de aplicações gráficas.

## 🎮 Sobre o projeto

O **PHANTOM 7** é um jogo 2D desenvolvido em Java, criado durante meus estudos de programação.

O projeto tem como objetivo colocar em prática conceitos de **Java, POO e desenvolvimento de interfaces gráficas**, construindo o jogo passo a passo.

## 🛠️ Tecnologias utilizadas

- ☕ Java
- 🖥️ Java Swing
- 🎨 Java AWT
- 🎮 Eventos de teclado
- 📦 Programação Orientada a Objetos
- 🔧 Eclipse IDE
- 🌱 Git e GitHub
