## 🎮 Sobre o jogo

O PHANTOM 7 é um jogo de ação 2D em que o jogador controla um personagem em um ambiente inspirado em jogos de combate espacial e ficção científica.

O projeto está sendo desenvolvido passo a passo, com foco tanto na construção das mecânicas quanto na organização do código e na evolução das minhas habilidades em Java.

## 🕹️ Funcionalidades

- 🎮 Movimentação do personagem por teclado.
- 🔫 Sistema de disparos.
- 👾 Presença de inimigos e mecânicas de colisão.
- 🌌 Cenários com imagens e recursos gráficos.
- 💀 Tela de Game Over.
- 🖥️ Interface gráfica desenvolvida com Java Swing e AWT.

*O jogo continua em desenvolvimento e novas funcionalidades serão adicionadas conforme o projeto evoluir.*

## 🛠️ Tecnologias utilizadas

| Tecnologia | Aplicação |

## ▶️ Como executar

Para executar o projeto localmente:

1. Instale um JDK compatível com o projeto.
2. Abra o Eclipse IDE.
3. Importe o projeto Java para o workspace.
4. Confira se a pasta `res` está presente e se os caminhos das imagens correspondem aos utilizados no código.
5. Localize a classe que inicia a aplicação e execute-a como uma aplicação Java.

*O procedimento pode variar conforme a configuração atual do projeto no Eclipse.*
